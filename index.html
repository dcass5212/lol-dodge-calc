Dodge window vs. move speed — selected boot

The model: For a linear non-tracking skillshot, optimal dodge direction is perpendicular to the missile path. You escape if your lateral displacement exceeds the combined radius S = r_champ + r_shot before impact. The dodge window — max reaction time that still escapes — is W(v) = (cast_delay + distance / missile_speed) − S / v, where v is your effective move speed after LoL's formula (flat → additive % → slow × (1 − slow_resist) → soft caps). Marginal value dW/dv = S / v² is always positive and always diminishing: your first boots help more than each upgrade, and a slow collapses the window faster than +20 MS rebuilds it.
